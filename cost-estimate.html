7. Баалоонун Негизи (Basis of Estimates)
Баалоо ыкмасы: Bottom-up Estimating (Төмөндөн жогору)
Болжолдоо негизи: Долбоордун ишке ашыруу процессинде өлчөнгөн реалдуу убакыт
Чектөөлөр: Бул жеке дипломдук иш; коммерциялык баалар колдонулган жок
Ишеним деңгээли: 94 500 ± 10%  (диапазон: 85 050 — 103 950 сом)
Убакыт диапазону: 290 — 340 саат

9. Жыйынтык
"Wanderlust" долбоору frontend + backend чогуу алганда болжол менен 315 саатта аяктады. Долбоор эки негизги техникалык бөлүктөн турат:
Frontend (185 саат) — Next.js 16 менен кесипкөй туристтик UI, 12+ баракча, Art Deco дизайн системасы
Backend (97 саат) — OpenAI Chat API (streaming) + Кыргыз үн кызматы (FastAPI, aitil.kg TTS/ASR, gTTS, kyrgyz_normalizer)
Тестирлөө (33 саат) — браузер тестирлөө, API жана үн сапатын текшерүү
Жалпы болжолдуу баасы 94 500 — 103 950 сом. Lighthouse аудити боюнча 96 / 100 / 100 / 100 натыйжасы алынды.
